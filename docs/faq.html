Getting Started

Findings and Results

A CONFIRMED finding means the generated PoC compiled successfully, ran through Foundry, and its security assertion passed. It proves the specific behavior exercised by the test — not every possible exploit variant.

The heuristic detected a suspicious pattern and generated a PoC, but Forge was unavailable or the test did not pass. A human must review the evidence and decide whether the finding is real.

No. It means SIREEN's current heuristics found no attack surface and every hypothesis received a Forge attempt. Business logic bugs, oracle manipulation, economic attacks, and novel vulnerability classes may still exist.

Reporting and Feedback

Contact the project owner through their GitHub profile with the contract source, the exact command, and the output. Include whether you were using heuristic or AI-assisted mode.

Open a GitHub issue describing the feature and why it would help. We prioritize features that improve the core verification workflow.
