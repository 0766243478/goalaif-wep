Getting Started

Do I need an API key to use SIREEN?

No. SIREEN works fully offline in heuristic mode. An OpenRouter API key is only needed if you want to enable optional AI-assisted hypothesis generation.

What are the minimum requirements?

Python 3.11+ and pip. Foundry (forge) is optional but strongly recommended if you want CONFIRMED findings. See the download page for full prerequisites.

Does SIREEN work on Windows?

SIREEN is tested on Linux and macOS. It should work on Windows Subsystem for Linux (WSL). Native Windows support is untested.

Findings and Results

What does "CONFIRMED" mean?

A CONFIRMED finding means the generated PoC compiled successfully, ran through Foundry, and its security assertion passed. It proves the specific behavior exercised by the test — not every possible exploit variant.

What does "needs_review" mean?

The heuristic detected a suspicious pattern and generated a PoC, but Forge was unavailable or the test did not pass. A human must review the evidence and decide whether the finding is real.

Does "clean_with_coverage" mean my contract is secure?

No. It means SIREEN's current heuristics found no attack surface and every hypothesis received a Forge attempt. Business logic bugs, oracle manipulation, economic attacks, and novel vulnerability classes may still exist.

AI-Assisted Mode

Is the AI mode free?

Yes. SIREEN uses OpenRouter's free-tier models by default. No credit card is required.

Does AI mode find more bugs?

We don't know yet. The AI pipeline is wired and functional, but we have not systematically evaluated whether it produces better findings than heuristic-only mode. Try it and let us know.

Is my source code sent to OpenRouter?

Yes, when AI mode is enabled. The contract source is sent to OpenRouter's API for analysis. Do not enable AI mode on sensitive or proprietary code you are not authorized to share.

Technical

Can I use SIREEN without Foundry?

Yes, but findings will be needs_review instead of CONFIRMED. You will still get hypotheses and generated PoCs, but no executable verification.

What Solidity versions are supported?

SIREEN analyzes Solidity source code directly. The generated PoCs use pragma solidity ^0.8.0. If your project uses a different version, you may need to adjust the PoC.

Does SIREEN support Vyper or other languages?

No. Only Solidity is supported at this time.

Reporting and Feedback

How do I report a false positive?

Contact the project owner through their GitHub profile with the contract source, the exact command, and the output. Include whether you were using heuristic or AI-assisted mode.

How do I request a feature?

Open a GitHub issue describing the feature and why it would help. We prioritize features that improve the core verification workflow.
