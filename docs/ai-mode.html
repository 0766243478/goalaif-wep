AI-Assisted Mode

SIREEN works fully offline with heuristic analysis. Enabling AI-assisted mode adds optional LLM-powered hypothesis exploration — but every AI suggestion still requires Forge verification before a finding is confirmed.

Getting Started Quick Start Guide Installation Core Concepts Reference CLI Commands AI-Assisted Mode Known Limitations Help FAQ

What AI-Assisted Mode Does

  • Scans contract source — The LLM reads the contract to understand its architecture, trust boundaries, and state transitions.
  • Suggests hypotheses — Proposes attack angles beyond the built-in heuristic patterns.
  • Still requires verification — Every AI-generated hypothesis goes through the same Forge verification pipeline as heuristic ones. No AI output is ever auto-confirmed.
Important

AI-assisted mode is wired but unevaluated for hypothesis quality. The pipeline has been tested for connectivity, but we have not systematically measured whether AI-generated hypotheses produce better, worse, or different findings than heuristic-only mode. Use it experimentally and report your experience.

Setup

Step 1 — Create a free OpenRouter account

  1. Go to openrouter.ai.
  2. Sign up (email or OAuth).
  3. Navigate to Keys and create a new API key.
  4. Copy the key (starts with sk-or-v1-).

No credit card is required. Free-tier models are used by default.

Step 2 — Configure SIREEN

cd goalaif/gaolaif/backend
cp .env.example .env.local

Edit .env.local and add your key:

OPENROUTER_API_KEY=sk-or-v1-YOUR-KEY-HERE

Step 3 — Verify it works

sireen audit ./Contract.sol --json | grep reasoning_mode

Expected output: "reasoning_mode": "LLM_ASSISTED"

Free-Tier Models

SIREEN uses the following free-tier models from OpenRouter:

  • Scanner: nvidia/nemotron-3-ultra-550b-a55b:free
  • Attacker: nvidia/nemotron-3-super-120b-a12b:free
  • Verifier: nvidia/nemotron-3.5-content-safety:free
  • Judge: nvidia/nemotron-3-super-120b-a12b:free
  • Documenter: cohere/north-mini-code:free
Privacy note

Source code is sent to OpenRouter's API. Do not enable AI mode on contracts you are not authorized to share externally. For sensitive code, use heuristic-only mode.
