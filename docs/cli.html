sireen audit

Run a security audit on one Solidity file. This is the only input the current CLI accepts.

One file per audit

v0.1.1 rejects directories. Passing a folder produces SIREEN Core v0.1 accepts one Solidity (.sol) file per audit. There is no --project flag, even though earlier drafts of this page mentioned one.

sireen audit <file.sol> [options]

Options:
  --json              Emit the full audit record as JSON to stdout
  --report [path]     Write a Markdown report. Without a path it writes
                      ./<audit-id>.md in the current directory

Examples

# Audit a single file with a Markdown report
sireen audit ./MyContract.sol --report

# Audit with JSON output
sireen audit ./MyContract.sol --json

# Write the Markdown report somewhere specific
sireen audit ./MyContract.sol --report ./out/report.md

sireen audits

List past audits stored in the local SQLite database.

sireen audits [options]

Options:
  --json              Emit the list as JSON
  --limit N           Maximum number of audits to return (default 50)

sireen show

Display the full details of a specific audit, including evidence packs.

sireen show <audit-id>

sireen report

Export an existing audit as a Markdown report.

sireen report <audit-id> --output report.md
