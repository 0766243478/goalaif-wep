Contact & Feedback

Contact the SIREEN project

This page lists only contact routes that actually work today. There is no email address, no contact form, and no support hotline — because there is no server behind this website to receive them.

Ways to reach us

Works today

Report a website or documentation bug

Open an issue on the public repository that hosts this website. Issues are enabled, so anyone with a GitHub account can file one and follow the reply publicly.

Works today

Reach the project owner

The owner's GitHub profile is public. It is the only direct channel listed here. Use it to ask about access, evaluation, or collaboration.

github.com/0766243478

There is no contact form and no email address. This site is a set of static files: it has no backend, no database, and no mail service. A "Send message" button here would either do nothing or silently discard your text, so we do not publish one. GitHub issues are the channel that actually reaches a person.

Requesting access to the SIREEN product

The SIREEN product repository is private and will stay private. https://github.com/0766243478/goalaif returns HTTP 404 for visitors, and that is intentional. If you want to evaluate the product itself rather than the website:

  • Contact the owner through the GitHub profile above and say what you want to evaluate.
  • Expect to be asked which contracts you plan to test and what you intend to publish.
  • Access is granted per person, not publicly. There is no self-serve signup.

Everything you need in order to judge SIREEN before asking for access is already public: the evaluation guide, the known limitations, and the honest product status table on the home page.

What to include in a bug report

A report that can be reproduced gets fixed faster. Please include:

  • The page URL where the problem happened.
  • What you expected, and what actually happened.
  • Your browser and operating system.
  • For CLI or product bugs: the exact command, the SIREEN version, and your Forge version (forge --version).
  • A screenshot if the problem is visual.

Security issues

If you find a security problem in this website or in SIREEN, do not open a public issue with exploit details. Contact the owner privately through GitHub first and allow time for a fix before any disclosure.

What we will not do

  • We will not ask you for your API keys, private keys, or seed phrases — ever.
  • We will not sell you an audit, and SIREEN is not a substitute for one.
  • We will not claim SIREEN found a vulnerability it did not execute and prove.
